# CareerAI – Lean Canvas

| Block | Content |
|---|---|
| Problem | Job seekers struggle to identify suitable roles; lack personalized career guidance; uncertainty about required skills. |
| Customer Segments | Students, fresh graduates, entry-level job seekers, career switchers. |
| Unique Value Proposition | A simple AI-powered career assistant that converts a user's skills, interests and location into personalized career paths and skill-gap suggestions. |
| Solution | Skill profiling, career matching, location-aware ranking, skill-gap analysis. |
| Channels | College placement cells, student communities, career workshops, social media, web app. |
| Revenue Streams | Freemium premium guidance, institutional subscriptions, recruiter partnerships (future). |
| Cost Structure | Hosting, development, maintenance, AI/ML infrastructure (future), job-data integrations (future). |
| Key Metrics | Number of profiles, recommendation completion rate, match interaction rate, returning users, skill-gap actions. |
| Unfair Advantage | Student-focused workflow combining career direction and skill-gap guidance in one lightweight platform; can later build a feedback dataset for better recommendations. |
